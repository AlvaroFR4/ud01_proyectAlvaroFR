# ud01_proyectAlvaroFR
# Practical exercise by Álvaro Fernández Rodríguez

This project calculates basic arithmetic operations, converts Celsius to Fahrenheit, and converts euros to US dollars using a fixed exchange rate of 1.08.

## How to run it
```bash
python3 src/main.py
```

## Example
```text
Introduce el primer número: 10
Introduce el segundo número: 5
Suma: 15.0
Resta: 5.0
Producto: 50.0
División real: 2.0
División entera: 2.0
Resto o módulo: 0.0
Potencia: 100000.0
Introduce la temperatura en °C: 20
20.0 °C = 68.0 °F
Introduce la cantidad en EUR: 100
100.0 EUR = 108.0 USD
```

## Project structure
- `src/`: contains the application logic in `main.py`
- `tests/`: reserved for automated tests
- `data/`: currently contains project data files (empty placeholder files)
- `docs/`: intended for documentation and project notes
